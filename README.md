  последних успешных банковских операций клиента. Этот проект, который на бэкенде будет готовить данные для отображения в новом виджете.**

##                       ***Задание первое***

2. Установка инструментов для проверки качества кода ***(Flake8, black, isort, mypy)***
3. Настройка файла *.flake8* для конфигурации линтера *Flake8*.
4. Добавление конфигурации для *black*, *isort* и *mypy* в файл **pyproject.toml**.
5. В пакете **src** создан модуль с названием **masks**. Здесь реализовано две функции:
 - Функция маскировки номера банковской карты **get_mask_card_number**.
 - Функция маскировки номера банковского счета **get_mask_account**.

###                      ***Как работают функции***

- Функция **get_mask_card_number** принимает на вход номер карты и возвращает ее маску. Номер карты замаскирован
  и отображается в формате XXXX XX** ****XXXX, где X - это цифра номера. То есть видны первые 6 цифр и последние 4 цифры,
  остальные символы отображаются звездочками, номер разбит по блокам по 4 цифры, разделенным пробелами. Пример работы функции:
  7000792289606361   входной аргумент 7000 79** ****6361 выход функции.

- Функция **get_mask_account** принимает на вход номер счета и возвращает его маску. Номер счета замаскирован и отображается в формате
   **XXXX, где X - это цифра номера. То есть видны только последние 4 цифры номера, а перед ними - две звездочки. Пример работы функции:
  73654108430135874305  # входной аргумент **4305 выход функции.

- Реализована запись логов в файл. Логи записываются в папку **logs** в корне проекта. Файлы логов имеют расширение **.log**.
  Формат записи лога в файл включают метку времени, название модуля, уровень серьезности и сообщение,
  описывающее событие или ошибку, которые произошли.

## Новые модули и функции

### Модуль `src/decorators.py`
В проект добавлен модуль `decorators.py`, содержащий универсальный декоратор `@log` для автоматического логирования работы функций.

### Декоратор `@log(filename=None)`
Декоратор регистрирует начало и конец выполнения функции, а также возвращаемые результаты или возникшие ошибки.

**Параметры:**
* `filename` (*Optional[str]*): Имя файла для записи логов. Если не указано, логи выводятся напрямую в консоль.

**Пример использования:**
```python
from src.decorators import log

@log(filename="my_log.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)
```

**Формат вывода при успешном выполнении:**
`my_function ok`

**Формат вывода при ошибке:**
`my_function error: TypeError. Inputs: (1, '2'), {}`

**Добавлены модули для работы с внешними данными и API:**
- `src/utils.py` — чтение и безопасная обработка списка транзакций из JSON-файла.
- `src/external_api.py` — конвертация сумм транзакций в рубли (RUB) с использованием актуальных курсов валют через **APILayer Exchange Rates Data API**.

## Тестирование

В проекте используются автоматические тесты для проверки корректности работы функций. Для запуска тестов используется библиотека `pytest`.

## Запуск тестов

Чтобы запустить все тесты в проекте, выполните команду в терминале:
```bash
pytest
```
Если вы хотите запустить тесты с выводом подробной информации (verbose):

```bash
pytest -v
```

### Структура тестов

Тесты расположены в папке `tests/` и покрывают следующий функционал:
* `test_processing.py` - тестирование функций обработки данных в модуле `processing.py`.
* `test_masks.py` - проверка работы масок и фильтров.
* `test_widget.py` - тесты для виджетов и интерфейсных элементов. 
* `test_generators.py` - тестирование функций фильтрации по валюте(включая пустые списки и отсутствующие валюты), генерации описаний транзакций и параметризованный тест для генератора номеров карт.

## Логирование

В проекте настроено автоматическое логирование для модулей `masks` и `utils`. Логи помогают отслеживать успешность выполнения операций и фиксировать возникающие ошибки.

### Особенности реализации:
- **Разделение логов:** Логи модуля утилит сохраняются в `logs/utils.log`, а модуля маскирования - в `logs/masks.log`.
- **Режим перезаписи:** При каждом новом запуске приложения файлы логов перезаписываются(`mode='w'`), что предотвращает избыточное разрастание файлов на диске.
- **Формат записей:** Каждая строка лога содержит метку времени, имя модуля, уровень серьёзности и информационное сообщение.

### Пример формата лога:
`2026-09-11 17:45:00 - src.utils - INFO - Файл по указанному пути успешно прочитан.`
